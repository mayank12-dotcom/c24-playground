# Local typefaces

The interface uses the original DM Sans and Space Grotesk families. These normal, variable-weight WOFF2 Latin and Latin Extended subsets are served by the application so an unavailable external font stylesheet cannot prevent startup.

The files were copied unchanged from the Fontsource Variable npm packages below. Each archive was verified against its registry SHA-512 integrity value. No npm dependency is needed at runtime.

- `@fontsource-variable/dm-sans@5.3.0`: https://registry.npmjs.org/@fontsource-variable/dm-sans/-/dm-sans-5.3.0.tgz
- `@fontsource-variable/space-grotesk@5.3.0`: https://registry.npmjs.org/@fontsource-variable/space-grotesk/-/space-grotesk-5.3.0.tgz

Both typefaces are licensed under the SIL Open Font License 1.1. Original copyright notices and full terms are included in [dm-sans-OFL.txt](dm-sans-OFL.txt) and [space-grotesk-OFL.txt](space-grotesk-OFL.txt).
